Không lấy được tự động? Dán transcript hoặc tải file .srt / .vtt

Trên YouTube: mô tả video → Show transcript → chọn tất cả, sao chép, dán vào đây (dòng thời gian và dòng chữ xen kẽ đều được). Hoặc dán nội dung file .srt / .vtt / XML phụ đề.
